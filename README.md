# F4Hud — Minecraft 建筑辅助画中画模组

**NeoForge 1.21.1** 客户端模组。按 **F4** 在屏幕**右上角**弹出一个固定不动的画中画小窗，实时渲染你**当前视角（旁观模式视角）**的画面；再按一次 **F4** 收起。

> 目的：建筑时不用再频繁切旁观模式飞来飞去盯视角。开着画中画，边建边能看到自己视角对准的位置。

---

## 功能

- 按 `F4`：右上角弹出画中画小窗，画面 = 玩家当前位置 + 当前朝向（旁观视角），**实时同步**。
- 窗口**固定在右上角**，移动、转头都不会跟着漂移，只实时更新画面内容。
- 再按 `F4`：收起。
- 纯客户端逻辑，装在服务端也不会崩溃。

## 安装

1. 游戏版本需为 **Minecraft 1.21.1 + NeoForge 21.1.x**。
2. 把 `f4hud-1.0.0.jar` 放进整合包的 `mods` 文件夹（若用启动器多版本目录，放到对应版本的 `mods` 里）。
3. 启动游戏，进游戏后按 `F4` 即可。

## 使用

| 按键 | 作用 |
|---|---|
| `F4` | 弹出 / 收起右上角画中画窗口 |

## 依赖

- `neoforge` `[21.1.0,)`（CLIENT）
- `minecraft` `[1.21.1,1.22)`（CLIENT）

## 从源码构建

需要 NeoForge 1.21.1 的运行时类路径（`client-1.21.1-20240808.144430-srg.jar` + `neoforge-21.1.248-client/universal.jar` + 版本 json 的库），用 javac 编译后按以下结构打包：

```
f4hud-1.0.0.jar/
├── META-INF/neoforge.mods.toml
├── pack.mcmeta
├── assets/f4hud/lang/{en_us,zh_cn}.json
└── com/example/f4hud/**/*.class
```
